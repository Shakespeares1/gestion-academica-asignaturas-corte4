# Guion para el video · Corte 4

Graba tu pantalla con tu cámara visible y usa tu propia voz. Trabaja con registros de prueba y deja el correo abierto únicamente para mostrar la llegada del mensaje. Oculta contraseñas, códigos de recuperación y credenciales de servicios.

1. **Presentación.** Di tu nombre, el número de ejercicio y el nombre de la app. Explica que conservaste la API de Gestión Académica y reemplazaste el cliente Kodular por Apache Cordova.
2. **Flujo de asignaturas.** Ingresa como administrador. Crea una asignatura de ejemplo, abre su detalle, cambia el profesor y elimina el registro. Puedes dejar otra asignatura para usarla en reportes.
3. **Flujo de usuarios.** Registra un usuario, muestra su detalle y edita el nombre o el username. Mantén esta cuenta hasta terminar el restablecimiento para luego mostrar su eliminación.
4. **Reportes.** Cambia un parámetro en cada informe y muestra cómo afecta al resultado. Usa una carrera y semestre, un rango de créditos, rol y estado, y un rango de fechas de registro.
5. **Recuperación.** Cierra sesión, pulsa **Olvidé mi contraseña**, abre el enlace recibido y cambia la clave. Comprueba que puedes iniciar sesión con la clave nueva.
6. **Código.** Abre `mobile/www/app.js` y explica cómo arma una petición REST y autentica con Bearer. Muestra una migración SQL, un controlador de reportes y el adaptador de correo del backend.
7. **Entrega.** Muestra en GitHub el repositorio público, el README y el APK. Publica el video en YouTube o Vimeo y prueba el enlace en una ventana privada.
